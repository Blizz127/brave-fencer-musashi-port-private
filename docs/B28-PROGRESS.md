## Run and gates

Memory on the box is tight (15 GB, shared with another job), so builds use
-j4 and run one at a time (baseline, then gate, then the strict run). Logs and
scratch live under `/workspace/scratch` (not /tmp, which a box restart wipes).
The scripts there are not part of the repo; rebuild them from this note if
they are gone.

Strict run (box):

    EXTRA_ENV="MUSASHI_DRIVER_TRACE=50 MUSASHI_STRICT_STOP_RAM=/workspace/scratch/stop_ram.bin" \
      FR=3000 TO=900 bash /workspace/scratch/srun.sh > /workspace/scratch/srun.out

`srun.sh` builds `build/b23-strict` (target musashi_native_boot, -j4), runs
the driver headless into `/workspace/scratch/strict.log` and prints the exit
code, the first `STRICT_INTERPRETER_ENTRY` (the stop line), any `HOST_FAULT`
and the last `FRAME_TRACE`. Run it detached (`setsid nohup ... & disown`).

Gates before each commit (`/workspace/scratch/gate.sh`, output gate.txt):

1. Build `build/b23-hybrid` (-j4), then `cmp` its
   `generated/native_lane/native_lane_table.c` with the pre-B28 copy (it must
   be identical). The pre-B28 copy is regenerated by running the generator
   from a detached b27 worktree (79fa85ee) with the hybrid flags into
   `/workspace/scratch/b27lane` (`baseline.sh`).
2. Hybrid ctest: 37/37.
3. `tools/check_no_m2c_text.py`.
4. `tools/check_no_retail_data.py --region main`: only the 2 known jtbl build
   failures (800626C8/800626DC) are allowed (needs the PsyQ gcc toolchain).
5. try.py MATCH for every new or changed source.

Box restart (increment 19): the box restarted and lost /tmp, the build trees
and the system packages. Recovery was apt reinstall, reconfigure both build
trees and regenerate the baseline. The reinstalled `libsdl2-dev` (unlike the
earlier sdl2-compat) does not pull in `<assert.h>`, so the PsyCross
`static_assert`s in libgpu.h broke the C build. CMakeLists.txt now force-
includes `assert.h` for the musashi C sources that include PsyCross headers.
